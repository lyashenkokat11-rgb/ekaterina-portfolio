САЙТ-ВИЗИТКА ЕКАТЕРИНЫ ЛЯШЕНКО

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Фото и PDF-резюме уже подключены из папки assets.

Видео:
Исходный видеофайл не найден в текущей рабочей папке. Чтобы добавить его:
1. Скопируйте видео-визитку в папку assets.
2. Назовите файл video-vizitka.mp4.
3. В index.html замените блок video-placeholder на:
<video controls playsinline preload="metadata" style="width:100%;display:block">
  <source src="assets/video-vizitka.mp4" type="video/mp4">
</video>

Для публикации в интернете загрузите всю папку portfolio_ekaterina на любой статический хостинг.
